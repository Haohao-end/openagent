# 实时执行 Trace

在受支持的实时聊天和工作流调试过程中，OpenAgent 可以显示 Callable Trace 时间线。它用于辅助查看执行过程，与最终回答或工作流输出并列展示。

## 事件与时间线

前端通过 `callable_trace` 流式事件接收 Trace。Schema 版本 1 的事件使用 `run_id` 标识一次运行，可通过 `parent_run_id` 关联父运行，并描述 `chain`、`llm`、`tool` 或 `retriever` 的生命周期。一次运行可以报告 `start`、`end` 或 `error`；载荷还可能包含名称、状态、输入、输出、错误和 `latency_ms`。

时间线按运行 ID 合并生命周期更新，忽略重复的事件 ID，并在父运行可用时将子运行嵌套显示。收到终态更新前，开始事件会保持运行状态。错误以及可用的输入、输出详情会显示在对应运行下。无效或不支持的事件会被跳过；事件列表为空时不显示空时间线。

## Trace 的生命周期

Trace 是临时流式数据，会随当前 UI 状态中的实时消息或调试运行保留；前端不会从持久化的 thoughts 或历史聊天记录中重建 Trace。因此，重新加载会话或拉取更早的历史页不会恢复先前的 Trace 时间线。开始新的实时调试运行即可收集该次运行的事件。
