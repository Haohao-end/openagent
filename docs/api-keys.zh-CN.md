# API Key

OpenAPI API Key 页面用于管理已发布应用的调用凭据。目前支持的权限范围是 `openapi:chat`，允许访问 `POST /api/openapi/chat`。新建密钥默认使用此范围。

## 失效时间和使用信息

- `expires_at` 是可选的 Unix 秒级时间戳。失效时间留空表示永不过期；之后也可以修改时间或清除失效时间。
- `last_used_at` 是可选的 Unix 秒级时间戳。字段缺失、为 null 或为 0 时，页面显示“暂无使用记录”。密钥通过身份验证和权限检查后，后端会尽力更新此信息。
- `scopes` 是受支持权限范围字符串的列表。空列表不会授予任何 API 访问权限。为兼容旧记录，`scopes: null` 仍表示不受权限范围限制，页面会将其标记为旧密钥。

新增字段之前创建的记录仍可使用：缺少失效时间表示永不过期，缺少最后使用信息表示暂无记录，null 权限列表保持原有兼容行为。编辑旧密钥并选择权限范围后，密钥会受所选范围限制。

## 密钥明文

完整 API Key 仅在创建成功后返回并显示一次。请立即复制并妥善保存；密钥列表会遮蔽凭据，之后无法在页面中重新查看明文。列表还会显示激活状态、失效时间、最后使用时间、权限范围和备注。
